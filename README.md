# Get Minecraft server data
This plugin, made in Visual Bukkit, gets information from your Minecraft server and sends it to a specific IP adress. The targeted device get a JSON payload that it can devour :)

## Examples
### ESP32
The ESP32 (code included) expects the payload and generates a message every time someone joins. Of course, you can change it to whatever you like. 
### Flanlang
All devices running [FlanOS](https://github.com/SemBL06/FlanOS) are able to use this payload too.
